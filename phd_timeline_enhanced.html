Benefit: Public health relevance. Precision medicine angle. Collaboration with population health researchers.

Benefit: Comprehensive systems biology perspective. Network analysis. Highly cited review potential.

💻 Backup Obj 5: Open-Source Database/Tool Development

Scope: Create interactive web portal for MTBC polymorphism database or TB susceptibility gene visualization tool.

Benefit: Software engineering angle. Community resource. Long-term research impact beyond thesis.

🧬 Backup Obj 6: Machine Learning Prediction Model

Scope: Build ML model to predict TB progression risk using combined MTBC genotype + Host genetics + clinical data.

Benefit: AI/ML relevance. Predictive medicine. Highly publishable in bioinformatics venues.
